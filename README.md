# Cyborg Rises

A small browser maze game. You are a cyborg escaping a lab. Find your way through the maze to the green exit.

## How to play

- **Goal:** move the cyborg (the glowing cyan square) from its starting square to the green exit square.
- **On a computer:** press the arrow keys. Each key press moves the cyborg one square.
- **On a phone or tablet:** tap the arrow buttons under the maze.
- Walls block your way. If you walk into one, nothing happens.
- When you reach the exit you will see **You escaped!**. Press **Play again** to start over.

## Run it on your computer

There is nothing to install. Open `index.html` in a web browser.

## Put it online with GitHub Pages

1. In the repository on GitHub, open **Settings** then **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the `main` branch and the `/ (root)` folder, then save.
4. After a minute or so GitHub shows the web address of the game.

## Project files

- `index.html` is the page layout.
- `style.css` is the lab-themed look.
- `game.js` holds the maze and the game rules.

The project uses plain HTML, CSS and JavaScript only: no frameworks, no build step and no npm packages.
