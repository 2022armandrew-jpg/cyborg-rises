# Cyborg Rises

A learning project: an original grid-based maze game in the browser. The owner directs and reviews; Claude Code writes the code.

## Stack

- Plain HTML, CSS and JavaScript only. No frameworks, no build step, no npm packages, so GitHub Pages can serve the files directly.
- Files: index.html, style.css, game.js.

## Rules

- Plan mode before building anything non-trivial. Ask clarifying questions rather than guessing.
- Keep changes small. Explain every change in plain English when you finish.
- Add a one-line plain-English comment above each block of code.
- Movement is grid-based: one square per key press, no free movement.
- Must work on desktop (arrow keys) and mobile (on-screen arrow buttons).
- Original characters and names only: nothing from Pac-Man or other existing games.
- Never commit secrets, API keys or passwords.
